# Ассортимент мерча 01:17

Источник: предоставленная папка «Мокапы мерча» в Google Drive. Изображения уменьшены и перекодированы из PNG в WebP для сайта; прозрачность сохранена.

В каталоге собраны 27 концепций по профессиональным линейкам и 10 базовых изделий. Два файла линейки «Сервис на транспорте» (значок и ремувка) отсутствуют в папке, поэтому их записи оставлены без изображения.

Макеты созданы для презентации ассортимента и не являются утверждёнными производственными файлами. Цены, размеры квот и остатки не заданы. Поэтому импортированные товары остаются черновиками с нулевыми остатками. Патч и рюкзак заведены отдельно как награды; welcome-набор и служебная форма отмечены в `catalog.json` как выдача из фонда.
