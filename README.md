# Степы — платформа студенческой активности

Платформа сделана по [ТЗ.md](ТЗ.md). Стек: Django 5 и PostgreSQL (локально — SQLite). Интерфейс — адаптивный сайт.

## Что уже работает (MVP)
| Модуль | Возможности |
|---|---|
| Вход | Логин и одноразовый пароль из импорта; при первом входе пароль нужно сменить. Вход через МЭШ по OAuth 2.0 + PKCE включается переменными окружения. Если студента МЭШ не удалось сопоставить, он попадает в очередь на ручную привязку |
| Студенты | Импорт из Excel с предпросмотром и ошибками по строкам, Excel с доступами, повторный импорт (переводы между группами, выбывшие), сброс паролей |
| Степы | Неизменяемый журнал операций, защита от повторного начисления, ручные начисления с лимитами, сторно, баланс не уходит в минус |
| Мероприятия | Календарь (месяц и список), аудитория (курсы и группы), запись, лимит мест, лист ожидания, файл .ics для календаря телефона. Чек-ин: **QR-код, который меняется каждые 30 секунд**, кодовое слово с защитой от подбора, отметка по списку |
| Задания | Ручная проверка (текст, ссылка, файлы) с очередью, доработкой и массовым принятием. Викторины с автопроверкой и квесты-цепочки. Лимит «первые N» |
| Опросы | 7 типов вопросов, аудитория, сводка по группам, выгрузка в Excel. Голосования, в том числе тайные (в базе нет связи «студент — голос»), с публичными итогами |
| Магазин | Варианты товара (размеры), остатки, лимит на студента, код получения, выдача по коду, отмена с возвратом степов, автоотмена невыданных заказов |
| Розыгрыши | Условия: N мероприятий за период, конкретное мероприятие, задание или опрос; аудитория. Кнопка «Участвую», автоматический или ручной запуск. Проверяемый результат: зерно (seed) и хэш списка участников |
| Вовлечение | Рейтинг студентов (по заработанным степам, за месяц, семестр, год) и групп (среднее на студента). Достижения — автоматические и ручные |
| Уведомления | На сайте (🔔) и **пуш на телефон** (Web Push, VAPID). Студент сам выбирает категории. Пуши ставятся в очередь и рассылаются сервисом `pusher`. Анонс новых мероприятий, заданий, опросов и розыгрышей при публикации, напоминания за 24 часа и за 1 час, объявления администрации (не больше 3 в сутки). Сайт можно установить как приложение (PWA, иконки) |
| Отчёты | Посещаемость, активность студентов, оборот степов, ручные начисления, магазин — всё выгружается в Excel. Журнал действий администраторов |

**Пока не сделано:** настоящие адреса и поля для входа через МЭШ появятся после подключения к СУДИР.

**Пуш на iPhone** работает только для сайта, добавленного на экран «Домой» (iOS 16.4+); на странице настроек есть подсказка. Пушам нужен HTTPS (локально работает на `localhost`).

## Локальный запуск (Windows)
```bash
py -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python manage.py migrate
.venv/Scripts/python manage.py seed_demo      # демо-данные
.venv/Scripts/python manage.py runserver
```
Откройте http://127.0.0.1:8000. Демо-доступы: `admin` / `admin12345` (суперадминистратор), `student1` / `student123` (студент).

Тесты: `.venv/Scripts/python manage.py test core`

## Где что у администратора
- `/staff/` — панель: ключевые цифры и быстрые действия.
- `/admin/` — создание мероприятий, заданий, опросов, товаров, розыгрышей, достижений; настройки валюты и лимитов.
- `/staff/import/` — загрузка студентов; `/staff/credit/` — начисление степов; `/staff/reports/` — отчёты.
- `/tasks/review/` — проверка заданий; `/shop/issue/` — выдача заказов по коду.
- QR-экран чек-ина открывается из списка мероприятий (ссылка «QR-экран»).

## Развёртывание на VPS
1. Сервер в РФ (4 vCPU, 8 ГБ RAM), Docker и Docker Compose, домен с A-записью.
2. `cp .env.example .env` и заполнить значения (ключи пушей: `python manage.py generate_vapid`); в `deploy/nginx.conf` указать свой домен; получить сертификат через certbot.
3. `docker compose up -d --build`, затем `docker compose exec web python manage.py createsuperuser`.
4. Резервные копии: ежедневно `pg_dump` и том `media` в объектное хранилище (п. 13.2 ТЗ).

Сервис `pusher` каждые 10 секунд отправляет пуши из очереди. Сервис `scheduler` каждые 5 минут выполняет `run_scheduled`: розыгрыши по расписанию, напоминания о мероприятиях, отмену невыданных заказов.
